# Benchmark data

Three task families for the cross-model compression-tolerance study
(see `docs/benchmark.md`), 40 tasks each:

- `extraction_relay.jsonl` — fact survival in verbose prose handoffs.
- `tool_plan_handoff.jsonl` — structural integrity of `tool_calls` under
  compression.
- `constraint_tracking.jsonl` — survival of hard constraints buried in filler.

These files are **generated, versioned artifacts**: they were produced by

```bash
python -m laconic.eval.generate --seed 7 --per-family 40 --out data/benchmark
```

and can be regenerated byte-identically with the same command. Do not edit
them by hand — change the generator and regenerate, so the dataset and its
provenance stay in sync.
