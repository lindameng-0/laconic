# Laconic

Find where agent handoffs lose declared requirements, test source-backed repairs,
and measure communication overhead. Laconic provides exact-text auditing and
bounded downstream replay alongside its compression, deduplication and profiling
tools.

Start with [handoff auditing and replay](handoffs.md), then reproduce the
[scripted experiment](experiments.md). The experiment executes behavioral
checks; it does not measure a language model or establish production savings.
